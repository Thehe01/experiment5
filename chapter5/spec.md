# 第五章漏洞攻击技术关联预测实验规范

目的：检验 R-GCN 邻域聚合是否改善已有节点之间缺失 exploited_by 边的排序，同时测量不同上下文关系的贡献。完整方案于 2026-10-10 获用户确认并授权实施。

## 已确认范围

REQ-001 保留六类实体与五类关系，仅评价 Vulnerability 到 AttackTechnique 的 exploited_by。预测保存为 UNVERIFIED，排序分数不解释为事实置信度。
REQ-002 主实验使用可追溯、证据核验的事实图；第四章冻结预测图作为单独补充实验。实际预测档案仅覆盖 21 篇旧 Dev，因此补充比较定义为：用真实 ProTeGi_Full 预测替换原 C4 Gold 边，保留共享的官方 ATT&CK/NVD 扩充；主图的核验标签仅用于补充图的 Dev/Test 评价，所有留出预测目标边同样删去。这是覆盖受限的图噪声敏感性分析，不称完整端到端预测图。禁止改写第四章冻结 Gold、结果或正式 Test 门禁。
REQ-003 固定 Enterprise ATT&CK v19.2 源提交，完整扫描 uses 过程示例。明确 CVE 和直接利用行为的官方记录可以作为来源确认关系；非利用技术、否定、歧义和仅共现记录进入 pending，不自动升级。记录原始内容、摘要、条目标识、引用及审核理由；不虚构人类复核或 IAA。
REQ-004 补充 NVD CWE 和 vulnerable=true 的受影响 CPE，保留配置条件和原始记录；按产品家族规范化 Configuration，版本范围作为属性保留。无信息时记缺失，不能猜测 CWE/CPE。所有下载有缓存、发送前账本、有限重试与可恢复状态。
REQ-005 按 CVE 分组划分，目标比例为 70/15/15。在可行范围保持技术分布，原材料已出现的 CVE 不进入新的最终 Test；来源曝光范围明确限定为仓库记录及第四章语料，不能宣称模型预训练未知。
REQ-006 Dev/Test 的目标边及逆向副本从消息传递、辅助重构训练和特征生成中同时删除。ATT&CK 战术与阶段上下文仅由冻结技术定义及预设规则产生，不读取留出目标边。冻结图、字典、split、代码和配置摘要；恢复时不匹配则拒绝。
REQ-007 Frequency、CWE Frequency、DistMult、R-GCN+DistMult 使用同一图快照和目标划分。两个学习模型共享训练三元组、类型约束负采样与目标/上下文加权损失；上下文参与辅助重构，最终只评价目标关系。负样本不得碰撞已知正例；留出 CVE 不作为目标关系训练负例的头实体。
REQ-008 三个 R-GCN 消融分别移除 affects、instantiates、implies 与 belongs_to_phase（后两类共同移除）；对应辅助损失同步移除，目标损失权重保持不变。消融沿用主 R-GCN 的已选超参数。
REQ-009 主指标为 filtered、按 CVE 等权的 MRR，辅以 Hits@1/3/10 和分技术指标。完整冻结技术候选域，其他已知真尾实体过滤；并列分数采用平均名次。另存逐边排名用于复算。
REQ-010 DistMult 与 R-GCN 各最多 8 组超参数，使用一个固定开发种子；最终各学习实验臂采用 5 个固定种子。补充图只运行 DistMult/R-GCN 各 5 种子，复用主实验已选超参数，不另搜索；总训练上限为 16 个开发配置 + 25 个主实验运行 + 10 个补充运行 = 51 次。Dev MRR 连续 30 epoch 未提升则早停，单次最多 500 epoch。只在所有配置与模型选择规则冻结后统一评价最终 Test；Test 输出不得影响后续选择。
REQ-011 原子检查点保存当前/最佳模型、优化器、epoch、早停计数、Python/Torch 随机状态、输入/代码/运行库摘要。续跑复用已完成结果与检查点，不重置搜索或训练额度。异常落盘；损坏或不匹配不回退为全新运行。
REQ-012 GitHub Actions CPU 在独立分支运行，数据和模型账本归档，依赖和线程数明确记录。新项目路径 chapter5/，不合并 main，不触发第四章推理。模型 API 调用预算为 0。
REQ-013 不以效果必须提高为完成条件。数据不足、稀有类别、来源失败、预测图覆盖不足等均如实报告；不能通过改标签、反复补样或测试集调参追求高分。阶段状态区分工程验证、数据冻结、训练中和最终评价完成。

## 验收案例

AC-001 对直接利用、利用后活动、否定和共现的对照材料，只有有直接证据的记录进入主目标集合（REQ-001/003）。
AC-002 多条重复证据归并为一条规范边，仍保留各来源；无 vulnerable 标记的运行环境 CPE 不变成 affects（REQ-003/004）。
AC-003 同一 CVE 多尾实体始终同组；已曝光 CVE 不进入 Test；所有集合覆盖且无重合（REQ-005）。
AC-004 故意放入留出正向/逆向边及目标派生上下文时，泄漏校验拒绝训练（REQ-006）。
AC-005 负采样只产生合法类型、不碰撞已知真例、不会将留出 CVE 用作目标负例头（REQ-007）。
AC-006 对含多真尾和并列分数的固定例子复算准确排名、CVE 等权指标（REQ-009）。
AC-007 训练中断后恢复与不中断运行得到相同状态；输入改动或检查点损坏时拒绝恢复（REQ-010/011）。
AC-008 小图运行全部模型和消融，验证消息方向、关系归一化、梯度、有限训练和最终选择；结果完整可复算（REQ-007/008/010）。
AC-009 实际远端日志提供采集/冻结/训练阶段、退出码与结果入口，无法核实的阶段不声明完成（REQ-012/013）。

## 边界与实施细化

图谱补全不证明新现实攻击事件。官方源事实构成主标签，不声称完成独立人类语义标注研究。第四章预测图的补充比较必须绑定其真实归档及覆盖范围，缺输入则明确标为 unavailable，不能用 Gold 冒充预测。
训练每个上下文关系分别求平均损失，按固定权重加入；避免边数悬殊主导目标。采集结束后、划分之前，以存在 affects/instantiates 上下文为固定建模资格条件；没有上下文的 CVE 连同完整来源另存并报告排除数，不能看分数后排除。无 Dev/Test 或剩余新的 Test 候选不足时停止主实验并报告。采集完成后冻结，不依据训练/测试分数补数据。

运行开始前将 active 预占记录持久保存。正常退出或失败时保存带 SHA-256 的全量分片；恢复只接受 closed 状态。若 runner 突然丢失，active 状态阻止重新采集或训练，需先恢复原始证据，不能假设零用量。270 分钟单个执行槽只为 Actions 留出归档时间；可恢复后续槽，不重置 500 epoch/搜索/请求上限。
