# 来源差异处理 v3

用户要求继续消除现有差异。目标是交付一个已知争议不进入训练/评分的可用数据视图，以及完整、可追溯的复核台账。本版本只准备数据，不启动实验。

## 决定与代价

- 不将不同提供方的 CWE 直接并集。对全部856个外部候选采用相同固定优先级：缓存 NVD 记录中 sourceIdentifier 对应的数字 CWE；缺失时采用 nvd@nist.gov 的数字 CWE；两者均缺失时，只接受逐条官方 CVE ADP 容器确认的 CISA 数字 CWE。Primary/Secondary 不用于推断提供方身份。提供方内部多条有效 CWE 保留，不做没有依据的层级压缩。
- 92个多源差异逐条定位缓存 JSON 原字段，并与固定 CVEProject 提交的 CNA 容器核对。固定优先级是本项目的使用口径，不宣称 CNA 或 NVD 永远语义正确。相异来源证据继续保存，不改写原快照。
- 20个 UNKNOWN 技术对照官方 CVE 记录与冻结 ATT&CK19.2定义形成 AI 核验意见，意见只进入复核台账，不能自动变为 Gold 或确认负例。不因CTID缺失认定作者错误。
- 12个含 UNKNOWN 的 CVE 暂时整体隔离出 usable 视图，避免只删除争议正例后误作负例。代价是 usable 从1736减少12个CVE，旧Dev150不再适用。全部1736记录保留在 full 视图，角色和技术标签保持；另保留v2的2条跨域隔离记录。隔离可逆，不称为语义裁决。
- 不人为均衡类别、年份或产品分布，不通过Dev指标选择来源。原880标签、856外部标签、CPE和原CWE快照均不覆盖；新视图的89项CWE选择作为独立候选输入。

## 验收

1. 1736个full记录完整；usable与本轮12项隔离严格分区，usable没有UNKNOWN。原v2的2项跨域隔离保持，总14项隔离。
2. 92条CWE差异有确定选择及原字段证据；89条候选CWE集合改变、3条无需改变。全部856项应用同一选择规则。
3. 20项意见集合恰好等于原UNKNOWN对，覆盖12个CVE、15个技术定义；没有任何AI正例或确认负例被写入数据。
4. 所有技术/CPE/原角色与v2一致，原880CWE不变；可用划分只删隔离ID，不移动其余角色、不重新分层。不读取或评分155个保留组标签。
5. 来源Git SHA及文件SHA256验证；行为测试包含来源身份、伪数字、外来提供方、整CVE隔离和未知对完整性。生成两次字节一致，覆盖与篡改拒绝。
6. 新数据与旧实验不直接可比。旧冻结36单位/23科学源绑定复核通过；没有新训练、模型推断、API、评分或登记。

## 后续边界

恢复12个隔离CVE需要明确语义口径和独立人工复核。开启新实验前需固定新候选包哈希、usable Train/Dev及评估类别、预算和科学登记。已见争议处理是开发数据准备，不能表述为盲测或性能改善。
