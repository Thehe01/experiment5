## 必须完成的处理

1. 保持 X/y 原始行配对；校验列名、行数、二进制标签、非空描述、有效 CVE ID。
2. 同一 CVE 的相同描述和相同标签可去重，保留全部来源坐标；描述或标签不一致时隔离，不投票、不自动取并集。
3. 保留组 ID 优先排除；完整原公开源、当前图池、既有曝光 ID 均不能作为新增训练样本。
4. 对新的 CVE 检查与原公开源描述的标准化完全重复：NFKC、casefold、空白归并。命中者单列隔离；不同新 CVE 之间的同文组记录共同分组标识。
5. 只有不重合、有效、无未决重复的记录进入 new-text-candidates.jsonl。角色为未分配的外部开发候选，不宣称正式新 Test。
6. 来源 CSV 不提供 CWE/CPE，输出空背景与 missing_graph_context 标记，不从技术标签猜背景。当前图模型新增可训练记录数量为 0。
7. 当前图池重合样本的标签差异，仅对开发池在共同 31 父技术范围内审计；不更改原标签、不给保留组生成标签差异评价。差异不自动认定某来源标错。
8. 按各折原 Train 统计原始粒度及父技术支持。额外样本的支持量仅作假设全部用于未来 Train 的预览，不据 Dev/保留组标签选类别或阈值。
9. 保存来源、逐项排除原因、重复及差异复核清单、映射、输入输出摘要、可复算脚本、测试回执和中文报告。
