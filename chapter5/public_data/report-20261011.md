## 标签范围和复核结果

公开 techniques 是 CTID 的利用方式、直接影响、后续影响并集，本轮目标命名 potentially_associated_with，绝不加入 v1 exploited_by。阶段分类分别保留，自动推导与预测字段完全剔除。

- 419 个 CVE 的三种阶段列表全部为空，但仍有专家并集标签；443 个 CVE 至少有一条未分类标签。保留这些专家关联，缺阶段标记为未分类，不推测属于哪一阶段。
- 107 个与 v1 重合的 CVE 中，49 个至少有一个 v1 标签未被公共并集覆盖，逐例双方标签保存在 v1-overlap-label-review.json。它们代表任务口径、证据语境或来源差异的复核线索，尚未裁决为任何一方的标签错误；不能盲目 union、intersection 或以新标签覆盖 v1。
- 1207 行中 393 行没有可解析的数字 CWE；322 行至少有一项未解析描述。原 Elevation of Privilege、CWE-noinfo 等均作为属性保留，不伪造 Weakness 节点。数据卡“CWE 列非空”不等于数字 CWE 覆盖。
- CPE 列缺 NVD vulnerable/configuration 条件，只构成 reported metadata。本轮用 has_reported_cpe，不声称已完成官方受影响产品核验。后续需要该语义时必须重新登记 NVD/厂商来源核验。
- 自己未开展真实双人独立标注，IAA 不可计算；CTID 专家来源声明单独保留。

暴露清单只覆盖指定 v1 图与既有仓库记录，不覆盖整个互联网/模型预训练。公开标签已被本轮读取用于数据审计，保留组不能写成从未被研究者接触的盲测。

## 下一阶段推荐方案

本轮完成的是数据准备登记，训练预算为 0。原 v2 推荐最多 81 次仅是候选规划，不能作为已执行或已登记预算。以下为下一轮具体依赖，不自动跑模型：

1. **固定问题。** 将此独立基准表述为“漏洞与潜在攻击技术关联排序”；v1 保留“来源确认的 observed exploited_by 关系恢复”。若论文必须只评价现实利用，需要逐例事件证据，现成 CTID 并集不能直接充当该目标的新增 Gold。
2. **建立独立训练登记与读图适配。** 绑定此包、代码、697 候选域、Dev/保留组角色与 CPU/依赖，明确接受 reported CPE 背景的语义限制；原 v1 reader 的固定关系表不能直接接收本包。新实现用独立路径，不修改 v1。保留组仍不参与开发评分/选优。
3. **先检验简单背景基线。** Frequency、CWE Frequency、先验平滑 CWE Frequency（alpha 1/5/10 仅 Dev 选择）、产品/CWE Train 邻居投票，全部同池同候选同划分。报告缺 CWE、有无共享背景、来源组和技术频率层；不能只看总分。
4. **受控开发。** 按此前规划，四臂 DistMult/R-GCN × 均匀/混合负采样；开发池 880 个 CVE，事先固定 3 个 CVE 分组开发折 × 3 个种子，共 36 次上限。67 个单样本技术不能随意分到无 Train 支持的折，折生成必须显式验证；混合采样只依据该折 Train 正例构建热门候选，仍排除已知真例，留出头不做目标负采样。10 个负例中 5 个全域、5 个 Train 已见技术，空已见池回退、空全域失败，留日志。多标签语义是未观察的训练对比，不能称已验证事实负例。
5. **开发停止条件。** 保留预先登记的最佳简单基线对照；推荐平均 Dev MRR 至少 +0.02、9 个组合至少 6 个改善、预定义主要技术宏平均下降不超过 0.01。主要技术按 Train 支持定义，不借保留组样本数选择类别。不达门槛归档开发负结果，不打开保留组寻找参数。
6. **一次性确认。** 仅开发通过且科学登记已冻结时，四个学习臂各 5 种子、混合 R-GCN 三组消融各 5 种子，35 次上限；全部训练结束后统一评价固定公开保留组。主指标 filtered macro-CVE MRR，辅以 Hits@1/3/10、技术宏平均和分组，平均种子后 CVE 配对 bootstrap。称公开基准的保留评价，不包装成独立前瞻现实攻击验证；与 v1 的 MRR 不作直接增幅比较。
7. **完整流程另行准备。** 当前公开 CVE 描述/CTID 映射不能替代第四章的新威胁报告 Test 和真实人类 IAA。没有覆盖这些 CVE 的独立抽取输入时，不开展原候选 10 次“完整预测图”补充，不解除 C4 门禁。

因此数据收集路线从“先手工凑 300～500 个现实利用 CVE”调整为“先做 1035 个 CVE 的独立潜在关联基准，现实事件样本针对缺口另行审计”。若研究目标不接受这一范围，停止在当前可复现数据交付，不能靠重命名关系伪造同一任务。
