# 第五章公开数据审计与适配规范

2026-10-11（UTC+8）。用户在现成数据调查后明确“开始”，本轮完成数据审计、独立适配、可复现数据包和后续方案，不把数据准备宣称为模型实验完成。

## 范围与要求

REQ-001 固定 CIRCL/vulnerability-attack-techniques 的不可变提交及两份 Parquet SHA-256；直接从这些字节读取，不以滚动 Dataset Viewer 作为生产输入。绑定 v1 图 SHA-256 与其中 ATT&CK 源 SHA-256，验证候选技术全集。
REQ-002 只使用专家整理的 techniques 作为“潜在关联”标签；保存 exploitation_techniques、primary_impact、secondary_impact 和未分类标签。绝不自动将其转成已观察的 exploited_by；缺阶段不能猜测。techniques_derived 和 cwes_predicted 不进入适配后的样本、图或特征。
REQ-003 每个 CVE 唯一，标签非空，描述非空，字段类型合法，阶段标签属于专家标签并集。无效行进入带原始身份及原因的隔离清单；重复 CVE、输入哈希错误、模糊/循环撤销映射、候选全集不一致阻断构建。无模型评分驱动的样本筛选。
REQ-004 将技术对齐冻结 Enterprise ATT&CK 19.2。已活跃编号原样保留；失效编号仅按明确唯一 revoked-by 链迁移并留痕，没有明确终点的行隔离，不通过父技术折叠扩大或缩小标签。
REQ-005 分别报告与 v1 标注、v1 全图、历史已记录曝光的交集。纯公开扩展池排除三者并集，去重后计算新增量，不将各来源数量相加。暴露范围只指仓库记录，不宣称模型预训练未知或公开标签从未被访问。
REQ-006 仅明确 CWE 数字编号产生背景节点，其余描述保留为待核对属性；合法 CPE 2.3 规范化产品家族，记录格式错误。CPE 信息缺少 vulnerable 标志和配置条件，使用 has_reported_cpe，不升级为 NVD affects。原始值保留以便复核。无合法 CWE/CPE 的行保留在无图背景集合，不强行造背景。
REQ-007 图目标关系独立命名 potentially_associated_with，阶段映射仅供审计；技术到战术/阶段背景只由冻结 ATT&CK 与已有固定规则产生。提供 CVE 分组的开发划分和 reserved_holdout，不评价后者；划分确定性，所有正例技术在 Train 至少出现一次，开发训练视图排除 Dev/保留组目标及逆向边，不能含目标派生背景。保留组不自动认证为独立正式 Test。
REQ-008 所有产物带 SHA-256、来源定位、确定性序列化和压缩包清单。独立验证重算数量、划分覆盖、目标隔离、源字段禁用和文件摘要。相同输入重建结果一致；输入变化后拒绝复用旧输出，不能部分覆盖后继续。
REQ-009 新代码、数据、登记和报告在独立 public_data 路径及分支；保留 v1 科学输入/代码/结果与 C4 门禁。当前训练预算 0，模型 API 0；仅允许公开数据文件下载、解析、离线检查与记录。新训练需要先完成对应科学登记，不从原 81 次候选预算推断实际运行。

## 验收

AC-001 真实不可变 Parquet 与摘要匹配，1207 个 CVE 的标签/阶段及上下游版本可追溯（REQ-001/002/004）。
AC-002 阶段缺失仍保留标签并标记未分类；自动推导/预测字段不出现在导出或背景图（REQ-002/006）。
AC-003 重复、非法标签、阶段并集冲突、错误摘要、撤销映射异常均按所述边界拒绝或隔离（REQ-003/004/008）。
AC-004 多来源重合计一次，既有曝光 CVE 不进入扩展池；伪 CWE 和格式错误 CPE 不生成节点（REQ-005/006）。
AC-005 多标签 CVE 不跨组，稀有标签保留 Train 支持，Dev/保留组正向与反向标签均不参与训练，标签派生背景被拒绝（REQ-007）。
AC-006 真实数据完整重建两次产物一致，篡改压缩包内产物被验证器拒绝；远端提交只改变允许的路径（REQ-008/009）。

## 实施假设与限制

专家标签身份由发布者/CTID 来源声明确认，本轮不冒充逐例独立人工重新裁决或计算 IAA。开发划分 70/15/15、种子 20261011 是本轮数据准备的实施选择；保留组尚未评分，后续登记前不得用于选优。字段不完整与同源/时间/产品偏倚均列入报告。公开潜在关联基准与 v1 现实利用关系恢复回答不同问题，绝不直接比较两者 MRR 为性能提升。
