# 公开数据适配计划

1. 绑定源 Parquet、冻结 v1 图与 ATT&CK 字节；审核原字段和任务语义。
2. 实现纯函数适配、曝光去重、背景规范化、按 CVE 的开发划分及训练视图；先 RED 后 GREEN，异常不绕过。
3. 从真实字节构建专家标签快照、扩展池、图、开发划分、隔离与审核队列、可复现 ZIP；独立验证并重建比较。
4. 报告样本量、阶段/背景缺失、长尾覆盖及跨来源标签差异。给出独立扩展实验方案，保留组不评分。
5. 独立分支保存代码/包/报告/检查证据，更新管理入口；对比 tree 确认原科学文件不变。

本轮不实施训练器、混合负采样或参数搜索。数据规范与完整后续训练注册分开，避免将工程准备算作完成实验。
